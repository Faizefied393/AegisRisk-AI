# AegisRisk AI — Executive Security Assessment

## Objective
Identify and prioritize software vulnerabilities using exploitation intelligence, technical severity and simulated business context.

## Methodology
Trivy vulnerability findings were correlated with CISA KEV and FIRST EPSS. A deterministic risk engine generated remediation priorities, while a local language model provided analyst-reviewed recommendations.
